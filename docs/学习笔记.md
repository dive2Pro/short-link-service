# 学习笔记

## 第一章

- Sprint Boot 通过注解搭建应用
- @RestController 代表是一个接口
- @RequestMapping 用于路由层级划分
- Record 是 java 中的 json


## 第二章

- Record 的另外一种创建方式: public record CreateLinkRequest(String: code){};
- dto 是 Data Transform Object 的缩写. 用于定义数据在业务中交互的结构
- @RequestBody 是 Sprint Boot 中用于获取请求中的 body, 并将其转化为传入的 record 结构

  @PostMapping("/api/links/{code}")
  public String create(
      @PathVariable String code,
      @RequestParam String source,
      @RequestBody CreateShortLinkRequest request
  ) {
      // POST /api/links/hello?source=web
      // code = "hello"
      // source = "web"
      // request 来自 JSON 请求体
      return request.originalUrl();
  }

## 第五章

- 短链服务是一个跳板服务. 先将一个长链接压缩后的服务链接(短链)和原始链接对应, 访问短链就会找出原始链接并跳转
- 原始链接可能是个错误地址. 异常处理不能忘记

## 第九章
